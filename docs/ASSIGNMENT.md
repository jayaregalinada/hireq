Overview
This is a short, focused technical screen designed to take no more than 30 minutes. It is not about perfection. It is about how you think, how you work, and how you communicate your decisions.
There is no right approach. What matters is that it works, that you can explain it, and that you followed the requirements.

What to Build
Build a simple web page that does the following:
Accept a job title as a text input (use Customer Success Manager as the primary example)
On submission, call an AI API and return 3 thoughtful interview questions specific to that role

Requirements
The page must be functional and the API call must work
Use an AI API provider of your choice. Gemini offers a generous free tier at ai.google.dev with no credit card required. Additional free options are listed at https://github.com/cheahjs/free-llm-api-resources. Paid tiers are acceptable if you choose to use them at your own cost.
Model selection is up to you — pick what you know or what makes sense for the task
Privacy and Security: Do not include any personal information such as names, phone numbers, or private resumes in your prompts or code. Stick to generic job titles
The UI does not need to be polished, but it should be clean and readable. Please include a basic loading state while the API is fetching the questions
Write code as if someone else will read it — clarity and simple error handling matter
Submit your code via a Github link and host your page live using a free hosting provider. Include the live URL in your submission so we can interact with your build directly

The Loom Video
Record a short Loom video of 4 to 7 minutes. In the video:
Introduce yourself
Show the working application in real-time.
Walk through your code and explain the key decisions you made, including the prompt you used. Please ensure to answer: What provider and model did you choose and why?
Answer the following questions:
Tell us one thing you would do differently or improve if you had more time.
What is your philosophy around building in general?
How do you collaborate with others when building?
How do you figure things out when you are stuck?

This video matters as much as the code. The ability to explain your thinking clearly to a non-technical person is a core part of this role.
